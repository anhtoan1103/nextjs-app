📊 Detailed Data Flow

Client Components (Browser)

  • page.tsx (Home) Manages global state, fetches transactions, calculates balance, coordinates all child components
  • Header & BalanceCard Displays current balance calculated from all transactions
  • StatsTabs Filters transactions by period (Week/Month/Year), calculates statistics, passes data to charts
  • TransactionList Displays all transactions, manages modal state, triggers data refresh after new transaction
  • AddTransactionModal Form with Ant Design components, validation, POST request to API

API Routes (Server-Side)

  • GET /api/transactions Fetches transactions from Supabase, supports filtering by date range and type
  • POST /api/transactions Validates request body, inserts new transaction into Supabase, returns created record

Database Schema (Supabase/PostgreSQL)

Column Type Constraints Description
id UUID PRIMARY KEY Unique identifier
type VARCHAR(10) NOT NULL, CHECK (income/expense) Transaction type
description VARCHAR(255) NOT NULL Transaction description
amount DECIMAL(10,2) NOT NULL, CHECK (> 0) Transaction amount
date DATE NOT NULL Transaction date
category VARCHAR(50) NOT NULL Category name
created_at TIMESTAMP DEFAULT NOW() Record creation time
updated_at TIMESTAMP DEFAULT NOW() Last update time

🔧 Utility Functions

formatters.ts

  • formatCurrency() - Converts numbers to USD format ($X,XXX.XX)
  • formatTransactionAmount() - Adds +/- prefix based on type
  • getCategoryIcon() - Returns emoji for category
  • getCategoryBgColor() - Returns color based on type

dateHelpers.ts

  • getWeekRange() - Returns start/end dates for current week
  • getMonthRange() - Returns start/end dates for current month
  • getYearRange() - Returns start/end dates for current year
  • formatDate() - Formats date as "MMM DD, YYYY"

calculations.ts

  • calculateStatistics() - Computes total income, expense, and net savings
  • calculateBalance() - Sums all transactions to get current balance
  • groupByPeriod() - Groups transactions by day/week/month for charts

🔄 State Management Flow

// page.tsx - Main state const [transactions, setTransactions] = useState([]); const [loading, setLoading] = useState(true); // Fetch transactions const fetchTransactions = async () => { const response = await fetch('/api/transactions'); const result = await response.json(); setTransactions(result.data); }; // Calculate balance const balance = calculateBalance(transactions); // Pass to components <Header balance={balance} /> <StatsTabs transactions={transactions} /> <TransactionList transactions={transactions} onTransactionAdded={fetchTransactions} />

⚡ Performance Optimizations

  • useMemo for Calculations Statistics and chart data are memoized to prevent unnecessary recalculations
  • Client-Side Caching Transactions are stored in React state, avoiding redundant API calls
  • Optimistic Updates UI updates immediately after adding transaction, then refreshes from server
  • Database Indexing Indexes on date and type columns for faster queries
  • Server Components Next.js renders components on server when possible for faster initial load
