1. Test Environment Setup

Prerequisites:
  • Node.js installed
  • Next.js dev server running on localhost:3000
  • Supabase project configured with credentials in .env.local
  • Transactions table created in Supabase database
  • Chrome/Edge browser (primary), Firefox/Safari (secondary)
  • Mobile device or Chrome DevTools for mobile testing
Test Data Required:
  • At least 5 sample transactions (mix of income and expense)
  • Transactions spanning different dates (week, month, year)
  • Various categories (Work & Salary, Food & Dining, Shopping, etc.)
2. Functional Testing

2.1 Page Load & Initial Render

TC-001 HIGH PRIORITY
Initial Page Load
Steps:
  1. Open browser and navigate to http://localhost:3000
  2. Wait for page to load
Expected Result:
  • Page loads within 3 seconds
  • Loading spinner appears briefly
  • Header displays with purple gradient background
  • Current balance shows correctly (or $0.00 if no transactions)
  • "Recent Transactions" section appears
  • Week/Month/Year tabs are visible
  • No console errors
TC-002 MEDIUM PRIORITY
Empty State Display
Precondition: Database has no transactions
Steps:
  1. Load the application
  2. Check the transactions section
Expected Result:
  • Message displays: "No transactions yet"
  • Subtitle: "Click 'Add Transaction' to get started!"
  • Chart shows empty/zero values
  • Stats show $0.00 for all values

2.2 Add Transaction - Success Cases

TC-003 HIGH PRIORITY
Add Income Transaction
Steps:
  1. Click "Add Transaction" button
  2. Select "Income" type
  3. Enter description: "Monthly Salary"
  4. Enter amount: 5000
  5. Select today's date
  6. Choose category: "Work & Salary"
  7. Click "Add Transaction" button
Expected Result:
  • Modal closes
  • Success message appears: "Transaction added successfully!"
  • New transaction appears in the list
  • Balance increases by $5,000.00
  • Statistics update (Total Income +$5,000)
  • Chart updates with new data point
TC-004 HIGH PRIORITY
Add Expense Transaction
Steps:
  1. Click "Add Transaction" button
  2. Select "Expense" type
  3. Enter description: "Grocery Shopping"
  4. Enter amount: 150.50
  5. Select today's date
  6. Choose category: "Shopping"
  7. Click "Add Transaction"
Expected Result:
  • Modal closes
  • Success message appears
  • New transaction appears in the list
  • Balance decreases by $150.50
  • Statistics update (Total Expense +$150.50)
  • Chart updates

2.3 Add Transaction - Validation & Error Cases

TC-006 HIGH PRIORITY
Validation - Empty Description
Steps:
  1. Open Add Transaction modal
  2. Leave description empty
  3. Fill all other fields
  4. Click "Add Transaction"
Expected Result:
  • Error message: "Please enter a description"
  • Modal stays open
  • Transaction not saved
TC-007 HIGH PRIORITY
Validation - Zero/Negative Amount
Steps:
  1. Open Add Transaction modal
  2. Enter amount: 0 or negative number
  3. Fill all other fields
  4. Click "Add Transaction"
Expected Result:
  • Error message: "Please enter a valid amount"
  • Modal stays open
  • Transaction not saved

2.4 Statistics & Filtering

TC-010 HIGH PRIORITY
Week Tab - Filter Transactions
Precondition: Have transactions from current week and previous weeks
Steps:
  1. Click "Week" tab
  2. Observe displayed transactions and stats
Expected Result:
  • Only current week's transactions shown in stats
  • Chart shows 7 bars (Mon-Sun)
  • Statistics calculate only for current week
  • Balance remains unchanged (shows all-time balance)
TC-013 HIGH PRIORITY
Statistics Calculation Accuracy
Precondition: Known set of transactions
Steps:
  1. Add 3 income transactions: $1000, $500, $750
  2. Add 2 expense transactions: $200, $150
  3. Check statistics
Expected Result:
  • Total Income: $2,250.00
  • Total Expense: $350.00
  • Net Savings: $1,900.00
  • Current Balance: $1,900.00

4. API Testing
TC-024 HIGH PRIORITY
GET /api/transactions - Fetch All
Steps:
  1. Open browser console
  2. Run: fetch('/api/transactions').then(r => r.json()).then(console.log)
Expected Result:
  • Status: 200
  • Response contains { data: [...], statusCode: 200 }
  • Data is array of transactions
TC-026 HIGH PRIORITY
POST /api/transactions - Create Transaction
Steps:
  1. Open browser console
  2. Run: fetch('/api/transactions', {method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({type: 'income', description: 'Test', amount: 100, date: '2026-02-24', category: 'Other'})})
Expected Result:
  • Status: 201
  • Response contains created transaction
  • Transaction appears in database
5. Security Testing
TC-036 HIGH PRIORITY
SQL Injection Prevention
Steps:
  1. Try to inject SQL in form fields
  2. Description: "'; DROP TABLE transactions; --"
  3. Submit transaction
Expected Result:
  • Input properly escaped
  • No SQL injection possible
  • Database remains intact
TC-037 HIGH PRIORITY
XSS Prevention
Steps:
  1. Enter script tags in description: "<script>alert('xss')</script>"
  2. Submit transaction
  3. Check if script executes
Expected Result:
  • Script not executed
  • Rendered as plain text
  • No XSS vulnerability
